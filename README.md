## Error Taxonomy Summary:

The following taxonomy defines the major categories of execution and programming errors considered in the dataset.

| Label | Category                          | Description                                                                                                                                                                                                                                                                                          | Manually Detected Examples                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A** | **Algorithmic Strategy Failure**  | Errors where the code implements an inherently incorrect algorithmic strategy, logic, or problem decomposition. The program may compile and execute without syntax or runtime errors, but the underlying approach does not satisfy the intended problem requirements.                                | Not manually detected                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **B** | **Interface & Formatting Errors** | Mismatches between the code's actual input/output and the intended specification. This includes parsing errors, formatting issues, function signature mismatches, incorrect parameter counts, incorrect naming, and incorrect externally expected data structures or types.                          | **IF01:** Expected output does not match actual output<br>**IF02:** Function signature / positional argument mismatch<br>**IF03:** Function called with an incorrect number of positional arguments<br>**IF04:** Function definition expects different positional arguments<br>**IF05:** Missing required positional argument<br>**IF06:** Multiple required positional arguments are missing<br>**IF07:** Numeric strings returned instead of numeric tuple output<br>**IF08:** Dictionary returned instead of expected tuple output |
| **C** | **Initialization & Scope Errors** | Errors caused by improper setup, reset, or isolation of variables and program state. This includes uninitialized variables, variable shadowing, failure to reset state, and incorrect sharing or maintenance of state across execution scopes.                                                       | **IS01:** UnboundLocalError involving `larger_number`<br>**IS02:** UnboundLocalError involving `char`<br>**IS03:** UnboundLocalError involving `sentence`<br>**IS04:** NameError: name `a` is not defined                                                                                                                                                                                                                                                                                                                             |
| **D** | **Data Type & Casting Errors**    | Errors where data is processed, assigned, or converted using incompatible, unintended, or semantically incorrect datatypes. This includes type mismatches, string/integer incompatibility, and floating-point precision issues.                                                                      | **DT01:** `TypeError: 'int' object is not iterable`<br>**DT02:** Floating-point precision/output discrepancy                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **E** | **Conditional Logic Errors**      | Flaws in conditional control flow and Boolean evaluation. This includes incorrect comparisons, inverted predicates, improper logical operators, unreachable branches, and failure to handle edge-case conditions.                                                                                    | Not manually detected                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **F** | **Iteration Errors**              | Logical and structural flaws in loops and repetitive execution. This includes infinite loops, off-by-one errors, incorrect iterator/index updates, faulty traversal logic, and prematurely skipped iterations.                                                                                       | Not manually detected                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **G** | **Mutability & Reference Traps**  | Bugs caused by improper management of mutable objects and reference semantics. This includes modifying collections while iterating, shallow-copy issues, unintended object sharing, aliasing, and unintended mutations between variables.                                                            | Not manually detected                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **H** | **Math & Transformation Errors**  | Errors where the code applies an incorrect computational or structural transformation. This includes arithmetic mistakes, incorrect operators or formulas, division by zero, sign errors, string manipulation issues, regular-expression errors, and flawed aggregation or sequence transformations. | **MT01:** `ZeroDivisionError: division by zero`<br>**MT02:** `ZeroDivisionError: float division by zero`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **N** | **No Error Detected**             | Represents cases where no execution error is detected or no applicable error category is identified.                                                                                                                                                                                                 | —                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

Semantic Validity: Embedding models do not cluster student submissions randomly or on superficial whitespace alone; they form distinct semantic manifolds capturing code length, nesting depth, and naming conventions.

Defensive vs. Idiomatic Taxonomies:

Cluster 3 captures defensive programming styles containing multiple input validations, higher AST edit distances, and compact naming.

Cluster 7 captures idiomatic implementations adhering closely to the canonical textbook quadratic formula.

Automated Interpretability: Combining GumTree AST diffing with surrogate tree-based classifiers provides an end-to-end framework to interpret and explain deep neural code clustering.
